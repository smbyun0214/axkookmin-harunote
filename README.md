# 📒 하루노트

메모·캘린더·할 일을 한 곳에서 서로 연결해 관리하는 웹 앱입니다.
할 일의 진행 과정은 **git처럼 main 줄기와 브랜치 그래프**로 기록됩니다.

> 국민대학교 AX-Startup 부트캠프 2기 실습 프로젝트입니다. 기획 내용은 [PRD.md](PRD.md)를 보세요.

---

## 실행 방법

설치할 것이 없습니다. (macOS에 기본으로 있는 `python3`만 있으면 됩니다)

### 방법 1: 서버 시작 버튼 (가장 쉬움)
1. Finder에서 이 폴더를 엽니다.
2. **`서버시작.command`** 파일을 더블클릭합니다.
3. 터미널 창이 열리고, 잠시 뒤 브라우저에 앱(`http://localhost:5001`)이 열립니다.
4. 끝낼 때는 그 터미널 창에서 `Ctrl + C`를 누르거나 창을 닫습니다.

> 처음 더블클릭할 때 "확인되지 않은 개발자" 경고가 나오면: 파일을 **오른쪽 클릭 → 열기 → 열기**를 누르면 됩니다. (한 번만 하면 됩니다)

### 방법 2: 터미널에서 직접
1. 터미널에서 이 폴더로 이동합니다.
2. 아래 명령을 실행합니다. (이 컴퓨터에서 앱을 보여주는 작은 서버를 켜는 명령입니다)
   ```bash
   python3 server.py
   ```
3. 브라우저 주소창에 `http://localhost:5001` 을 입력합니다.

> 💡 5000번이 아니라 5001번을 쓰는 이유: macOS에서는 "AirPlay 수신 모드"가 5000번을 이미 쓰고 있어서 충돌합니다.
> `server.py`는 브라우저가 옛 파일을 기억하지 않게 해서, 코드를 고친 뒤 새로고침하면 바로 반영됩니다.

## 화면 구성

왼쪽 사이드바에서 화면을 고릅니다. (창이 좁으면 아이콘만 보입니다)

| 메뉴 | 하는 일 |
|---|---|
| 오늘 | 오늘 일정·남은 할 일·완료 숫자, 오늘 일정·할 일·최근 메모 |
| 메모 | 메모 쓰기·검색·태그·고정, 문장을 할 일/일정으로 만들기 |
| 캘린더 | 월간/주간 보기, 날짜별 일정·할 일·메모 |
| 할 일 | 오늘/예정/완료됨. 할 일을 열면 **오른쪽에 그 할 일의 git 그래프**가 보임 |
| 히스토리 | 앱 전체의 main 줄기와 할 일 브랜치를 git 그래프로 보기 |
| 하루 기록 | 날짜별로 그날 한 일 모아보기 |
| 배경 | 누를 때마다 **자동 → 흰색 → 검은색** 으로 바뀜 (새로고침해도 유지) |
| 휴지통 | 지운 항목 30일 보관·복구 |

## 할 일 히스토리 (git 방식)

앱 전체에 **main** 줄기가 하나 있고, 할 일마다 **브랜치(가지)** 가 생겼다가 사라집니다.

| 할 일에서 한 일 | 히스토리에 남는 것 |
|---|---|
| 할 일 추가 | main에서 그 할 일의 브랜치가 갈라짐 |
| 마감일·우선순위·제목 등 수정 | 그 브랜치에 기록(커밋)이 쌓임 (예: `마감일 11/30 → 12/1`) |
| 완료 체크 | 브랜치가 main에 **합쳐지고(merge)** 브랜치는 사라짐 |
| 삭제 (휴지통) | 브랜치가 합쳐지지 않고 그대로 끝남 |
| 완료 취소 / 휴지통에서 복구 | main에서 새 브랜치가 다시 갈라짐 |

- **히스토리** 화면: 전체 그래프 + 선택한 기록의 자세한 내용(무엇이 바뀌었는지, 이 할 일의 기록 목록)
- **할 일 창** 오른쪽: 그 할 일 하나의 작은 그래프. 기록을 누르면 히스토리 화면의 그 위치로 이동합니다.

## 샘플 데이터

앱을 **처음 열면 샘플 할 일 100개가 자동으로 만들어집니다.** (버튼을 누를 필요 없음)
- 자소서·면접·공부·프로젝트·회고·네트워킹·부트캠프·일상·독서·포트폴리오 10가지 주제
- 최근 6주 동안 추가·수정·완료한 것처럼 히스토리도 함께 만들어져, 그래프를 바로 볼 수 있습니다.
- 약 90개는 완료(main에 합쳐짐), 6개는 진행 중, 4개는 휴지통에 있습니다.
- 샘플을 다시 만들고 싶으면: 브라우저 개발자 도구에서 이 사이트의 저장 데이터를 지우고 새로고침하세요.

### 사용 팁
- **메모 → 할 일/일정**: 메모 창에서 문장을 드래그해 선택하고 "할 일로 만들기" 또는 "일정으로 만들기"를 누릅니다. 선택하지 않으면 커서가 있는 줄을 씁니다.
- 문장 속 `12/3`, `12월 3일`, `내일`, `오후 3시`, `14:30` 같은 표현은 날짜·시간으로 자동 입력됩니다. (규칙 기반이며, 더 똑똑한 인식은 2단계 AI 기능입니다)

## 알아 둘 한계

- **데이터는 이 브라우저에만 저장됩니다.** 다른 기기나 다른 브라우저에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 함께 사라집니다.
- **알림은 앱이 브라우저에 열려 있을 때만 옵니다.**
- **반복 일정을 고치면 모든 회차가 함께 바뀝니다.**
- 히스토리는 할 일만 기록합니다. (메모·일정은 기록하지 않음)

## 직접 바꿔 볼 수 있는 부분

| 바꾸고 싶은 것 | 파일 | 고칠 곳 |
|---|---|---|
| 강조 색 | `css/style.css` | 맨 위 `:root` 안의 `--accent` |
| 배경·글자 색 | `css/style.css` | `:root`의 `--bg`, `--surface`, `--text` (검은색 배경은 아래 `data-theme="dark"` 부분) |
| 사이드바 아이콘 색 | `index.html` | 각 메뉴의 `style="--tile: var(--blue)"` |
| 첫 화면 | `js/app.js` | `DEFAULT_VIEW = 'today'` |
| 그래프 줄 높이·가지 간격·색 | `js/versions.js` | `ROW`, `LANE`, `MAIN_COLOR`, `BRANCH_COLORS` |
| 히스토리 한 번에 보여줄 기록 수 | `js/versions.js` | `PAGE = 60` |
| 샘플 할 일 내용·개수 | `js/samples.js` | `TOPICS`, `OPEN_COUNT`, `REMOVED_COUNT` |
| 휴지통 보관 기간 | `js/store.js` | `TRASH_DAYS = 30` |
| 할 일 알림 시각 | `js/notify.js` | `TODO_REMIND_TIME = '09:00'` |
| 서버 포트 | `server.py`, `서버시작.command`, `.claude/launch.json` | `5001` (세 곳을 함께) |

고친 뒤에는 브라우저에서 **새로고침**하면 바로 반영됩니다.
